# Мониторинг ресурсов

Скрипт мониторинга системы. Каждоые 60 секунд записывает в лог-файл результат выполнения команд ```free -h``` ```df -h``` ```uptime```

## Запуск
```
chmod +x script.sh
./script.sh
```

## Функции скрипта

* Проверка наличия команд
* Запись в файл результат выполнения команд
* При привышении размера файла в 10МБ выполнение ротации в monitor.log.ol
* Корректное завершение Ctrl+C 

## Настройки скрипта

|Переменная|Значение по умолчанию|Описание|
|--|--|--|
|INTERVAL|60|Интервал опроса в секундах|
|LOG_FILE|./monitor.log|Путь к лог-файлу|
|MAX_LOG_SIZE|10 * 1024 * 1024|Порог ротации|
